# 路慢慢 App UI 与内容决策记录

最后更新：2026-09-09

这是本项目的长期设计依据。后续即使聊天上下文压缩或更换智能体，也必须先读本文件、`IMPLEMENTATION-LOCK.md` 和 `references/` 中的原始参考图，不能依赖对聊天内容的印象。

## 一、协作流程（最高优先级）

1. 一次只设计一个页面或一个局部细节。
2. 先输出设计图给用户查看，不直接改 Flutter App。
3. 用户明确确认 UI 后，才能实施对应页面。
4. 禁止在用户尚未确认时大批量修改页面、素材、字体、图标或信息结构。
5. 用户指出一个局部问题时，只调整该局部，不得借机重做其他区域。
6. 不确定时必须先核对本文件和参考图；仍有冲突才询问用户。

## 二、总体视觉方向（已确认）

- 产品名：路慢慢。
- 整体方向以 `references/five-page-approved-direction.png` 为准。
- 气质：安静、温暖、生活化、带陪伴感，保留纸张/浅网格质感。
- 主色：暖米白、深墨绿、低饱和橙色点缀；不要杂乱，不要突然加入不属于这套系统的颜色。
- 猫狗不是反复粘贴的两个头像，而是陪伴型视觉角色；要根据页面功能、宠物的真实动作、身体形态和情绪安排位置。
- 可增加不同的猫狗元素，但每处都必须服务页面内容，避免堆满贴纸。
- 中文正文应使用清楚、自然、统一的系统中文字体；不使用用户已否定的奇怪手写体。否定示例见 `references/font-rejected-example.png`。

### 名言

- 不强制凑满 200 条。
- 删除此前由智能体自行编写的 100 多条内容。
- 只保留：用户给出的文字、用户截图中的句子、此前已经由用户认可的内容。
- 人民日报类句子应积极向上，但不能把无法确认来源的内容擅自标成《人民日报》。来源不确定时必须标记待核实。
- 用户写的“傻子”署名句子可以加入，但必须随机打散，不能连续多天出现，以免造成反感。
- “郑、雯、然、天、下、第、一、好”是拆开的彩蛋，每项独立出现，不得在列表中连续排列，也不得明示解释彩蛋。
- 用户提供的完整文字与截图索引已永久保存到 `work/design-spec/USER-QUOTE-INPUT.md`，后续不得只凭聊天记忆整理。
- 首页名言只显示句子正文，不显示“用户提供”“来源待核验”“出处待核验”“示例排版”等内部编辑说明。
- 来源核验信息只保存在本地资料中，不作为 App 界面文案展示。

### 夸夸墙

- 用户于 2026-09-01 明确确认 `mockups/praise-wall-v1.png`（含标题完整显示修正版）。
- 该效果图现为“夸夸墙”实施基准；未经用户提出新的局部修改，不再调整其布局、猫狗动作和纸条关系。
- 目标：让用户真的有想夸自己的欲望，但界面必须简洁。
- 删除用户已明确认为多余的两组引导文案，参考：
  - `references/praise-copy-remove-1.png`
  - `references/praise-copy-remove-2.png`
- 不用复杂问卷式引导，不要连续堆多层标题、副标题和解释。
- 猫狗可以参与递纸条、守着便签、露头或陪伴，但不要每条夸夸都重复同一个头像。
- `mockups/praise-wall-v1.png` 中猫狗以完整身体动作共同递出第一张纸条，第二张夸夸独立呈现；页面不加入额外引导文案。
- “夸夸墙”三个标题字必须完整显示，任何猫狗素材或底色层都不得遮挡、裁切标题笔画。

#### 2026-09-04 跨天排列规则（已确认并实施）

- 所有夸夸都永久保存在本机并显示在夸夸墙，不因跨天或数量增加而丢弃、覆盖或隐藏。
- 每天第一条夸夸在当天进入顶部猫狗递出的特殊纸条；当天第二条及后续夸夸使用普通便签继续向下排列。
- 第二天记录第一条夸夸后，新一天第一条进入顶部特殊纸条；此前日期的全部夸夸向下进入历史排列。
- 历史排列按日期从近到远，同一天内部保持第一条、第二条、第三条的原记录顺序。
- 顶部次数只统计今天的夸夸数量；历史记录显示必要的日期与时间。
- 不为该规则添加引导文字、提问文案、副标题或解释说明。

## 六、素材使用原则

- 用户提供的具体照片优先级高于任何生成素材。
- 当用户说“用这张”时，该附件就是锁定对象；不能自行理解为“做一张相似的”。
- 对其他宠物照片，也要依据原有动作和情绪设计：躺着、探头、依偎、眨眼等状态应分别处理，不套用统一爪子模板。
- 已有两个简单心情头像不能成为全 App 唯一猫狗素材。

## 七、禁止事项

- 禁止把生成的相似宠物图冒充用户指定原图。
- 禁止先改代码后给用户看。
- 禁止一次性重做所有页面。
- 禁止对已确认页面进行顺手优化。
- 禁止为了“可爱”而堆满猫爪、头像、贴纸和装饰。
- 禁止使用奇怪的手写字体承载正文。
- 禁止自行扩写大量名言或伪造出处。
